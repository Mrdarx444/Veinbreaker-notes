- This Map is using ***`Azerty`*** Keyboard.

| *Action*        | *Key*        | *Mobile Input*                     | *Use Cases*                                    |
| --------------- | ------------ | ---------------------------------- | ---------------------------------------------- |
| **`Left`**      | *`Q` or `A`* | `Joystick Left`                    | Player **Move to Left**                        |
| **`Right`**     | *`D`*        | `Joystick Right`                   | Player **Move Right**                          |
| **`Up`**        | *`Z`*        | `Joystick Up`                      | Player **Aim Up**                              |
| **`Down`**      | *`S`*        | `Joystick Down`                    | Player **Aim Down**                            |
| **`Jump`**      | *`Space`*    | Press `Jump` Button                | Player **Jump / Double Jump / Wall Jump**      |
| **`Dash`**      | *`Shift`*    | Press `Dash` Button                | Player **Dash / Roll / Dodge**                 |
| **`Melee`**     | *`MRB`*      | Press `Melee` Button               | Player **Attack / Finish**                     |
| **`Parry`**     | *`MLB`*      | Press `Parry` Button               | Player **Parry**                               |
| **`Handgun`**   | *`A` or `Q`* | Press `Handgun` Button             | Player **Shoot**                               |
| **`Use`**       | *`E`*        | Press `Use` Button<br>(Contextual) | Player **Pick up / Open / Close / Talk / Use** |
| **`Map`**       | *`Tab`*      | Press `Map` Button                 |                                                |
| **`Inventory`** | *`I`*        |                                    |                                                |
| **`Skills`**    | *`T`*        |                                    |                                                |
| **`Menu`**      | *`Esc`*      |                                    |                                                |
